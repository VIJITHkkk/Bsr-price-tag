# Fish Poster Studio

Daily fish, meat and piece-meen price poster maker (A4, print / save as PDF).

## Features
- Fish, Piece Meen and Meat categories with search
- Editable name, MRP and offer price
- Premium themes, custom themes with live preview, delete themes
- Photos for items, banner / background photo, logo
- Split (shop banner) layout and card layout

## Deploy on GitHub Pages
1. Upload `index.html` to a public repository
2. Settings > Pages > Branch: main > Save
3. Open `https://<username>.github.io/<repo>/`

No build step or dependencies. Single HTML file.
